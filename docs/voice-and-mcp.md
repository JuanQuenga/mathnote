# Connect MathNote to ChatGPT Work or Codex Voice

MathNote cannot start a ChatGPT subscription conversation from the Android app. The supported subscription path runs in ChatGPT or Codex: that client calls MathNote's MCP tools to read a synced page, and can send highlights and feedback back to the tablet. The Linux server does not make OpenAI model API calls. [OpenAI's MCP guide](https://learn.chatgpt.com/docs/extend/mcp) distinguishes hosted remote plugins from local Codex MCP connections.

## Local Codex MCP on the Linux host

1. On the Linux host, from this repository, run `./scripts/mathnote-desktop start`. It starts the tablet bridge and registers the local MCP server with Codex. Scan the private QR with the tablet Camera and open the link in MathNote; you can also tap MathNote's **Connect** button and paste the pairing link. Keep the tablet and Linux host on the same trusted LAN. Turn on **Live sync** for the page you want reviewed. If QR scanning fails, run `./scripts/mathnote-desktop pairing --show-token` and enter the address and token manually. The page snapshot and tutor marks travel through that bridge.
2. Run `./scripts/mathnote-desktop status` to check the bridge and Codex registration. If firewalld may block the tablet, the setup prints the exact optional firewall commands. It does not change firewall settings. Use `./scripts/mathnote-desktop stop` when finished; only a bridge started by that command is stopped.
3. Restart the ChatGPT desktop app or Codex host. In a new Codex task, type `/mcp` and check that `mathnote` is connected. The [official Codex MCP guide](https://learn.chatgpt.com/docs/extend/mcp) says the desktop app, CLI, and IDE extension share MCP configuration on the same host. A registration on this Linux machine does **not** automatically register the server on another desktop computer.
4. If your desktop app offers Voice in that Work or Codex task, say: "Use MathNote. List my synced pages, open my current calculus page, tell me the first step you question, and give me a hint. If the writing is unclear, ask me what it says. Mark the step on my tablet and write the hint there too." Keep MathNote open so it can poll for marks. The [ChatGPT Voice guide](https://learn.chatgpt.com/docs/features/voice) documents Voice in desktop Chat, Work, and Codex tasks. The tool calls still depend on the task's permissions and your account's rollout.

The [Linux desktop app](https://learn.chatgpt.com/docs/linux/linux-app) is in preview. Its documentation does not specifically confirm Voice availability on Linux. Local Codex MCP registration is verified on this Linux host, but a Linux desktop Voice call through MathNote has not been tested. If the Voice control is absent, use a typed Codex task with the same prompt. Windows and macOS desktop Voice are documented, subject to account rollout.

MathNote's MCP tools are `list_synced_pages`, `get_page`, `mark_page`, `write_feedback`, and `clear_tutor_feedback`. `get_page` returns the PNG with a revision; writes require that revision, so feedback for an earlier page state is rejected. Markup never edits student ink. In a desktop voice chat, ChatGPT speaks its response itself. `write_feedback` only shows text on the tablet; it does not send audio to the app.

If you use a different computer for ChatGPT desktop, run the bridge and MCP process where the page data is available, or connect that desktop host to a properly secured remote MCP endpoint. Local Codex configuration always belongs to the host that runs the client. A `localhost` URL on the tablet or another PC refers to that device, not this Linux box.

## ChatGPT Work on the web

[Developer mode](https://developers.openai.com/api/docs/guides/developer-mode) supports Plus and Pro personal accounts on the web and permits read and write MCP tools. [OpenAI's personal-plugin quickstart](https://developers.openai.com/plugins/quickstart) uses Settings → Security and login → Developer mode, then ChatGPT Plugins → plus button to register an HTTPS `/mcp` URL. Install the resulting personal plugin, open a Work chat, and invoke it with `@MathNote` or select it from the tools menu. Ask it to call `get_page`, then `mark_page` and `write_feedback` after explaining the first questionable step. Write calls may ask for confirmation.

The local MCP listener is intentionally bound to `127.0.0.1` and has no per-user OAuth. **Do not point an internet tunnel directly at it.** ChatGPT Work cannot read a local Codex `config.toml`; it needs a remote HTTPS endpoint or [Secure MCP Tunnel](https://developers.openai.com/plugins/deploy/connect-chatgpt). The [private gateway](../gateway/README.md) provides an OAuth-protected resource server and TLS proxy example for one owner. It still needs your public HTTPS address and an OAuth provider that supports ChatGPT's authorization flow. [OpenAI's MCP server guide](https://developers.openai.com/plugins/concepts/mcp-server) calls for the MCP authorization flow for private data and actions. The [Secure MCP Tunnel](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels) requires a Platform tunnel ID and runtime API key, so it does not meet a strict no-Platform-access setup. The gateway has local protocol tests, but no remote ChatGPT login has been completed.

## ChatGPT Work Voice on the Android tablet

OpenAI's [ChatGPT Work and Codex guide](https://help.openai.com/en/articles/20001275-chatgpt-work-and-codex) says Work Voice is available on Android and can ask Work to use connected apps. The [plugin guide](https://learn.chatgpt.com/docs/plugins) says plugins available to your account can be used in mobile Work. This is the route to test if you want the spoken tutor on the tablet to inspect a live MathNote page and send marks back. It requires MathNote to be a connected, authenticated remote plugin first. The local Codex registration from the section above cannot reach the Android ChatGPT app on its own.

The unresolved point is narrower: [developer mode](https://developers.openai.com/api/docs/guides/developer-mode) documents creation of a personal Plus/Pro MCP plugin on the web, but this project has not tested whether that specific personal plugin appears and works in **Android Work Voice**. After installing the remote plugin, start a new Work conversation in ChatGPT Android, select the MathNote plugin if offered, start Voice, and ask it to list synced pages. Then test `get_page`, spoken reasoning, `mark_page`, and `write_feedback` against the page open in MathNote. If the plugin is missing, that account or surface cannot complete this path yet.

Ordinary **Chat Voice** is a different path from **Work Voice**. Do not assume an MCP plugin available to Work Voice is available in ordinary Chat Voice. MathNote's **Check in ChatGPT** share action still offers a quick manual fallback: it sends a PNG to the ChatGPT Android app, where you can discuss the shared image. That share flow cannot write marks or feedback back to MathNote. The Android app's built-in local voice question and spoken answer also remain separate from ChatGPT Voice.

## A useful first voice test

With a synced page open, ask Voice to "list my MathNote pages". Confirm the page title appears. Next ask it to open the page and describe the first two handwritten lines. If it misreads them, correct the transcription before asking for a hint. Finally ask it to underline the specific questionable step and put a short hint in the tablet's tutor panel. The underline and hint should appear within a few seconds while MathNote is open. Change the ink and repeat; stale marks should disappear, and the server should reject an old revision.

The local MCP protocol and mark storage have automated tests. A Codex CLI session using the configured local MCP opened a synthetic calculus page, correctly identified Step 2 as wrong, and wrote an underline and hint; the saved annotations were checked directly. Desktop Voice and Android Work Voice have not yet been exercised with MathNote. Use the sequence above as a manual acceptance test on your own tablet and account.
